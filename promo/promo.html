02
01痛点

想在服里加个 AI 玩家，
通常卡在这三件事

  • ✕服务器不让装插件没有权限，也不想动服务端
  • ✕开游戏挂后台卡顿、掉线、还烧显卡
  • ✕现成的机器人只会复读不会聊天，更不会陪人玩

所以这个项目换了个思路 —— 机器人不进游戏本体，而是「模拟一个玩家」连进去。

03
02解决方案

纯客户端机器人，服务端一个插件都不用装

1
NO GAME CLIENT

不用打开游戏

Python 图形界面控制 Node.js（mineflayer）无头进服。MC 本体不用装、不用开，电脑也不用来回切窗口。

2
ANY SERVER

任意服务器可用

对服务器来说它就是一个普通玩家：不用服主配合、不用改配置、不用申请权限，换个 IP 就能用。

3
LLM DRIVEN

大模型驱动

OpenAI 兼容端点（也支持 Anthropic）。系统提示词、人格模板、上下文窗口、触发词、冷却都能调。

离线 / LittleSkin / 微软正版 掉线自动重登 · 被踢自动重连 踢出后自动执行 /lobby

07
06把人留在服里

好感度 · 签到 · 幸运值

AFFINITY

好感度

聊天 +1（5 分钟冷却）、点歌成功 +2（1 分钟冷却）、每天首次互动再 +1。
六级：陌生人 → 脸熟 → 熟人 → 朋友 → 好朋友 → 挚友，随时查自己或别人的分数。

CHECK-IN

每日签到

金币随机 + 连签加成，还能给物品奖励；奖励用两行命令发放，命令与文案都能改。
连签天数、累计次数长期保存，重启不丢。

LUCKY

今日幸运值

每天第一次被问到时随机定下来，当天不再变化。
值写进本地 SQLite，关掉程序、重启电脑也还是同一个数字。

每日数据统一走 daily.db：跨天自动备份旧库、重建新库，签到记录和连签连续不断。

07活跃气氛

推荐视频、群发通知，服主的手

BILIBILI

视频推荐

发一句提示词，公屏推一批 B 站视频：标题 + 备注 + 可点击链接。
来源五选一：番剧追番榜 / 首页推荐 / 首页热门 / 全站排行 / 我的收藏夹（填 Cookie 后可下拉选夹子，随机翻页抽）。 全服共用冷却，冷却过后再点自动换一批新的。

BROADCAST

群发私聊

开活动、发公告时一个个私聊过去，每个玩家之间有间隔（默认 0.5 秒），不会被当成刷屏踢下线。
也能随时私聊单个人，或者给所有在线玩家来一句「今晚 8 点开黑」。

每日幸运值视频推荐签到帮助好感度 以上全部认自定义提示词，不是 [点歌]

10
09细节都做完了

长期挂着也不用人管

AUTO

掉线自愈

连接意外结束按设定延迟自动重连，次数可限；被踢出重连成功后自动执行 /lobby。外置登录 5xx / 超时按指数退避重试，提示最多每 60 秒一条。

BOOK

文档转书

把 .docx / .doc / .txt 按书页宽度自动换行、按行数翻页，在游戏里写进书与笔；支持署名成书、记录进度、续写、暂停停止。

LOG

日志按天存

公屏、私聊、公告、ActionBar 与程序日志全部入内存，跨天或关闭时写成 logs/yyyy_mm_dd_第N次.txt，事后可查。

EXTRA

还带这些小工具

自动答题、自动进食（旧项目保留）；本地图片 HTTP 服务；低血量自动喊话；界面可换背景图与字体主题。
