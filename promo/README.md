# 宣传片（网页版）

一个**自包含**的动态宣传页：单个 HTML 文件，离线可用、无任何外部依赖（不用联网、不加载 CDN 字体），1920×1080 画布自动缩放铺满窗口，适合**直接全屏录屏**做成宣传片。

## 打开

双击 `promo.html`，或拖进 Edge / Chrome，按 `F11` 全屏。

| 操作 | 作用 |
| --- | --- |
| `空格` | 播放 / 暂停（右上角出现 PAUSED） |
| `←` `→` | 上一页 / 下一页 |
| `R` | 从头重播 |
| `F` | 进入 / 退出全屏 |
| `H` | 显示 / 隐藏底部提示条 |
| 鼠标静止 2.5 秒 | UI（圆点 + 提示）自动隐藏，方便录干净的画面 |
| 点击画面左 / 右半边 | 上一页 / 下一页（投屏演示时好用） |

## 录成视频

1. OBS → 场景 → 来源「显示器采集」，输出分辨率 **1920×1080**、**60 fps**，编码用显卡硬件编码（NVENC / QSV），录 MP4。
2. 浏览器 `F11` 全屏，鼠标挪到画面外或多等两秒让 UI 消失。
3. 按 `R` 从头播放，同时点开始录制；结尾停 1 秒再停止录制。
4. 想**逐页精修**（比如某页要多停一会儿）：用 `?scene=N` 直接定格第 N 页，一页录一段，剪辑时拼起来。

```
promo.html?scene=4          # 定格在第 4 页（自动播放会停下）
promo.html?scene=4&clean    # 定格 + 完全隐藏 UI
```

9 个场景、默认总长约 **60 秒**；每页停留秒数改 `promo.html` 里的 `var DUR = [5, 5.5, 6, 8, 8, 7.5, 6, 6, 8];`。

## 改成你自己的

- **文字**：直接在 `promo.html` 里搜关键词改，每个场景是一个 `<section class="scene" data-scene="N">`。
- **配色**：改文件顶部 `:root` 里的变量（主色 `#7ee787` 绿、`#58a6ff` 蓝、`#d2a8ff` 紫），全局替换即可换风格。
- **机器人名**：把 `DiaoHelper` 换成你的触发词 / 机器人 ID。
- **加页**：复制一个 `<section class="scene">`，给它 `data-scene="10"`，再在 `DUR` 数组末尾加一个秒数即可（圆点会自动增加）。

## 已经是录屏素材的地方

- 想插真实 GUI 截图 / 游戏内画面：在对应场景里加 `<img src="shot.png" style="width:1100px;border-radius:20px">` 即可，图片放同目录。

## 备注

- 页面**不联网**：没有网络也能渲染（字体用系统自带「微软雅黑」）。
- 需要 PPT 版（每页一张 16:9 幻灯片，可自行加动画/配音）也可以再做一份，说一声就行。
