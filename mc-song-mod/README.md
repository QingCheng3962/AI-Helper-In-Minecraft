# 点歌 Mod（songmod）

**客户端 Mod（Fabric 1.21.1 ~ 26.2）**：机器人用**会员账号**解析歌曲 → 把播放数据**私聊发回点歌的人** →
**谁点谁听**（只有点歌的人会响）；机器人不在线时本 Mod 会**本地兜底**自己搜歌。

- 机器人在它自己的「点歌」页**扫码登录网易云会员**，看到 `[点歌]歌名` 就用会员账号解析出**可播放直链**，
  默认用 `/msg` **私聊**发回给点歌的人 —— 聊天里看不到，别的玩家也不会跟着响（VIP 歌也是完整版）。
- 「谁点谁听」两层保险：① 机器人私聊发；② Mod 侧 `onlyMySong`（只播**文案里带自己名字**或**自己最近点过**的歌）。
  想改成“全服一起听”：机器人 GUI 取消勾选「只放给点歌的人」+ 本 Mod 配置 `"onlyMySong": false`。
- 机器人不在线（或没登录）时，本 Mod 会**本地兜底**自己搜歌播放
  （想放 VIP 完整版，可在游戏内「点歌台」里填**自己的**网易云 Cookie）。
- 声音从**系统音频**出（Java 自带音频 + 内嵌 MP3 解码 JLayer），和游戏声音同时响。

> 为什么必须靠聊天？因为机器人是**普通玩家（客户端）**，服务端又动不了，**客户端不能给别的客户端发数据**；
> 服务器会把公聊/私聊送给对应客户端，这是唯一能“送达”的通道。服务端**零改动**。

## v0.3.6 新界面（1.21.x 与 26.x 都有）

按 **K**（可在「按键设置 → 点歌 Mod」改）或聊天发 `[点歌]台` 打开新版「点歌台」：

| 页签 | 内容 |
| --- | --- |
| **点歌** | 歌名/链接/歌曲 id 输入；**可拖动的进度条**（显示 当前/总时长）；播放/暂停、停止；**倍速 0.5 / 0.75 / 1.0 / 1.5 / 2.0**；**歌词模式**（动作条 / 标题 / 聊天 / 关）；实时歌词预览 |
| **一起听** | 列出服务器上正在听歌的玩家（歌名 + 已播时间），点「一起听」**按对方进度跟播**；可刷新名单 |
| **我的** | 我点过的歌；音量滑条；自己的网易云 Cookie（机器人不在线时本地兜底用） |

### 播放引擎（v0.3.6 重写）

- 点歌后先**整首下载**并建 MP3 帧索引 → 所以能**精确跳转**（拖动进度）、**倍速**、暂停/继续，进度是真实播放位置。
- 倍速是 **PCM 线性重采样**：速度变快/慢时**音调也会跟着变**（和视频倍速一样），不是变调不变速。
- 不是 MP3（或解析不出帧）时自动退回 **JLayer 流式播放**：能听，但拖不动、不能倍速。

### 聊天语法（新增）

| 你说 | 说明 |
| --- | --- |
| `[点歌]歌名 1.5` | 末尾写倍速（0.5/0.75/1.0/1.5/2.0），只影响自己 |
| `[点歌]一起听` | 要一起听名单（机器人私聊返回） |
| `[点歌]一起听 玩家 [倍速]` | 加入某个玩家的一起听（机器人按估算进度返回播放数据 + `at:` 起点） |
| `[点歌]歌词` | 循环切换歌词显示方式 |
| `[点歌]歌词 动作条/标题/聊天/关` | 直接指定歌词显示方式 |
| `[点歌]倍速 1.5` | 只改倍速，不点歌 |

### 配置（config/songmod.json 新增）

- `speed`：上次用的倍速（下次点歌沿用）
- `showLyrics` / `lyricMode`（action/title/chat/off）/ `lyricPrefix`
- `lyricTitleFadeIn` / `lyricTitleStay` / `lyricTitleFadeOut`：标题模式淡入淡出毫秒
- `listenTogetherEnabled` / `listenRefreshSeconds`

## 消息里那串“乱码”是什么

不少服务器的聊天插件会把 `http(s)://…` 整条替换成 `[链接]`，Mod 就收不到直链了（表现：机器人明明发了，Mod 却干等 30 秒走本地兜底）。
所以机器人发的是**混淆直链**：

```
[点歌]Steve 点了一首 起风了 | ¤m801·music·126·net¦20261017…¦…·mp3 id:1330348068
```

| 记号 | 含义 |
| --- | --- |
| `¤` / `¥` | `http://` / `https://`（**整条消息不出现 `http`、`://`、`.`**，绕过链接过滤） |
| `·` `¦` `∶` | 原来的 `.` `/` `:`，Mod 收到后原样还原 |
| `id:3399839173` | 第二道保险：万一直链被服务器改动，Mod 用歌曲 id 自己取链（填了 Cookie 就是完整版） |

⚠ 不能用 `#`（会被服务器当十六进制颜色码吃掉）也不能用 `&`（MC 颜色符）。

## 游戏内「点歌台」界面（1.21.x）

装好后按 **K**（可在「设置 → 按键 → 点歌 Mod」里改），**或在聊天里发 `[点歌]台`**，打开：

- 输入 **歌名 / 网易云链接** → 点「**点歌**」（机器人解析后**放给自己听**）；
- 显示 **正在播放** 与 **我点过的歌**；
- 填 **自己的网易云 Cookie**（含 `MUSIC_U`，浏览器里抓）→ 点「保存 Cookie」；
- 「停止」按钮。

> **26.x 版没有游戏内界面**（Minecraft 26.x 的渲染 API 大改），点歌/播放/兜底功能一样，只是没有这个界面。

## 指令（在聊天里发）

| 指令 | 作用 |
| --- | --- |
| `[点歌]告白气球` | 点歌。机器人（在线时）私聊回你播放数据 → **你自己**听到（VIP 完整版）；机器人不在线 → 本地兜底 |
| `[点歌]help` | 让机器人**私聊**你全部用法（歌名 / 停止 / 台 / help / 登录 / 链接或 id） |
| `[点歌]台` | 打开游戏内「点歌台」界面（按键打不开时的备用入口） |
| `[点歌]停止` | 停止**自己**的播放（别人的歌不受影响） |
| `[点歌]https://music.163.com/song?id=123456` | 按**网易云链接**点歌 |
| `[点歌]123456` | 按**歌曲 id** 点歌 |

> Mod 只认**你自己发的**指令：别人在公屏发 `[点歌]歌名`/`[点歌]停止` 不会影响你（也不会触发你的本地兜底）。

## 版本与依赖

- Minecraft **1.21.1 ~ 26.2**（Fabric）
- 需要 **Fabric API**
- Java **21**（26.x 需要 Java **25**）

## 配置 `config/songmod.json`

```json
{
  "trigger": "[点歌]",
  "stopWord": "停止",
  "loginWord": "登录",
  "logoutWord": "登出",
  "guiWord": "台",
  "volume": 0.8,
  "provider": "163",
  "neteaseCookie": "",
  "localFallback": true,
  "onlyMySong": true,
  "botName": "",
  "modUrl": "",
  "hintText": "提示：没装点歌 Mod 的人听不到，请前往 {url} 下载",
  "maxKeywordLength": 60
}
```

| 字段 | 说明 |
| --- | --- |
| `trigger` | 触发词。聊天里出现它，后面的内容才被当作点歌。 |
| `stopWord` / `loginWord` / `logoutWord` / `guiWord` | 停止 / 登录 / 登出 / 打开界面词，默认 `停止` / `登录` / `登出` / `台`。 |
| `volume` | 音量 0~1。 |
| `provider` | 音源，目前只有 `163`（网易云）。 |
| `neteaseCookie` | **自己的**网易云 Cookie（含 `MUSIC_U`）；本地兜底要用。可在游戏内「点歌台」界面里填。 |
| `localFallback` | 机器人不在线时是否**本地兜底**自己搜歌（默认 **true**）。有机器人在线时**优先用机器人**。 |
| `onlyMySong` | **只播给自己的歌**（默认 **true**）：播放数据必须来自机器人，或匹配自己 5 分钟内点过的歌；不再因为正文里出现自己的名字就接受。 |
| `botName` | 机器人游戏名（推荐填写）：设置后只接受该发送者的点歌数据，防止别人伪造 `[点歌]你的名字 + 恶意链接`。留空时退回「最近点歌关键词」匹配。 |
| `modUrl` / `hintText` | 播放成功后要不要在聊天里提示别人装 Mod（`{url}` 替换成 `modUrl`）；留空不提示。 |
| `maxKeywordLength` | 歌名最大长度。 |

## 构建

需要 **JDK 25**（Fabric Loom 1.19 要求）。

- **1.21.x**：用 **Mojang 官方映射（mojmap）** + 重映射 Loom；源码在 `src/main/java` + `src/legacy/java`（含界面）。
- **26.x**：Minecraft 已**未混淆**且渲染 API 大改 → 用**非重映射** Loom、Java **25**、无 mappings；源码在 `src/main/java` + `src/modern/java`（无界面）。

```bash
./gradlew build "-Pmcver=1.21.11"        # 单版本 (Windows)
powershell -ExecutionPolicy Bypass -File build_all.ps1   # 1.21.1~26.2 全量
```

产物在 `dist/`，命名 **`Song_<项目版本>_<游戏版本>.jar`**，例如 `Song_0.1.0_1.21.11.jar`。

## 已知限制

- 只有**装了本 Mod** 的玩家能被“送到”歌；音频走系统设备（不跟随游戏内音量滑条，在配置里调 `volume`）。
- 26.x 无游戏内「点歌台」界面。
- 直链有约 20 分钟有效期，点歌即播没问题。
- 服务器如果连 `/msg` 私聊也做链接过滤，混淆直链同样能过（消息里没有 `http`/`://`/`.`）。
